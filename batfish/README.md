# Phase-0 learning material — not part of the pipeline

The Batfish tutorial built in an earlier session: a 10-module manual, 12
PyBatfish scripts, and 15 Cisco IOS snapshots. It is preserved because the
learning value is real and the manual's internal paths still resolve.

**Nothing here feeds the pilot.** The pilot's artifacts live in `data/pilot-v1`
and are generated by `pipeline/build_pilot.py`. These snapshots are Cisco IOS;
the pilot is FRR. Do not mix them.

`scripts/m09_frr_spike.py` here is superseded by
`pipeline/spike_frr_batfish.py`, which runs the same checks against the real
artifact instead of a toy.
